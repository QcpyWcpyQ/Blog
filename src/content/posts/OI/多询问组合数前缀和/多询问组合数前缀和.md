## 问题与约定

给定 $q$ 组询问，每组询问给定 $n,m$，求

$$
F(n,m)=\sum_{k=0}^{m}\binom nk.
$$

其中各参数同阶。答案对 $P=998244353$ 取模。

复杂度分析中，$n,m$ 分别表示所有询问的第一维、第二维最大值，$q$ 表示询问数。单次询问记作 $(n_i,m_i)$，代码中的 `N,M` 对应这里的 $n,m$。辅助多项式子程序会单独说明 $n,m$ 对应的输入规模。

## 1. 直接递推：$\mathcal O(mq)$

对于一次询问，设 $c_k=\binom nk$。由

$$
c_0=1,\qquad c_k=c_{k-1}\frac{n-k+1}{k}
$$

依次求出 $c_1,c_2,\ldots,c_m$，边递推边累加即可。

因为 $m<p$，分母 $1,2,\ldots,m$ 在模 $p$ 意义下都有逆元。先线性预处理逆元，每次询问就只需要 $\mathcal O(m)$ 时间，总时间为 $\mathcal O(mq)$，空间为 $\mathcal O(m+q)$。

这里不必预处理到 $n$，也不必要求 $n<p$：分子先对 $p$ 取模即可。当 $m>n$ 时，递推到 $k=n+1$ 会得到零，后面的项也都是零。

### 代码

```cpp
#include<algorithm>
#include<iostream>
#include<utility>
#include<vector>
using std::cin;
using std::cout;
using std::ios;
using std::max;
using std::pair;
using std::vector;
using i64=long long;
const int P=998244353;
inline int dec(int a,int b){return(a-=b)<0?a+P:a;}
inline int mul(int a,int b){return (1ll*a*b%P+P)%P;}
inline void add(int &a,int b){(a+=b)>=P?a-=P:1;}
int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    int q,M=0;
    cin>>q;
    vector<pair<i64,int>>ask(q);
    for(auto&[n,m]:ask){cin>>n>>m;M=max(M,m);}
    vector<int>inv(M+1);
    if(M)inv[1]=1;
    for(int i=2;i<=M;i++)
        inv[i]=dec(0,mul(P/i,inv[P%i]));
    for(auto[n,m]:ask){
        int x=n%P,c=1,s=1;
        for(int k=1;k<=m;k++){
            int numerator=dec(x,k-1);
            c=mul(mul(c,numerator),inv[k]);
            add(s,c);
        }
        cout<<s<<'\n';
    }
}
```

### 杨辉三角离线递推：$\mathcal O(nm+q)$

如果 $n$ 也很小，可以使用

$$
\binom nk=\binom{n-1}{k}+\binom{n-1}{k-1}.
$$

把询问按 $n$ 分组，从第 $0$ 行开始逐行计算组合数，再对当前行求前缀和，回答这一行的所有询问。使用滚动数组，更新组合数时必须从右向左，防止覆盖上一行的数据。

这样总时间为 $\mathcal O(nm+q)$，空间为 $\mathcal O(n+m+q)$。这种做法只用加法，甚至不要求模数是质数；但 $n$ 很大时就不能用了。

```cpp
#include<algorithm>
#include<iostream>
#include<utility>
#include<vector>
using std::cin;
using std::cout;
using std::ios;
using std::max;
using std::pair;
using std::vector;
using i64=long long;
const int P=998244353;
inline int inc(int a,int b){return(a+=b)>=P?a-P:a;}
inline void add(int &a,int b){(a+=b)>=P?a-=P:1;}
struct Query{int n,m,id;};
int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    int q,N=0,M=0;
    cin>>q;
    vector<Query>ask(q);
    for(int i=0;i<q;i++){
        cin>>ask[i].n>>ask[i].m;
        ask[i].id=i;
        N=max(N,ask[i].n);M=max(M,ask[i].m);
    }
    vector<vector<pair<int,int>>>at(N+1);
    for(auto v:ask)at[v.n].push_back({v.m,v.id});
    vector<int>c(M+1),pref(M+1),ans(q);
    c[0]=1;
    for(int n=0;n<=N;n++){
        if(n){
            for(int k=M;k>=1;k--){
                add(c[k],c[k-1]);
            }
        }
        pref[0]=c[0];
        for(int k=1;k<=M;k++){
            pref[k]=inc(pref[k-1],c[k]);
        }
        for(auto[m,id]:at[n])ans[id]=pref[m];
    }
    for(int x:ans)cout<<x<<'\n';
}
```

## 2. 莫队：$\mathcal O(n\sqrt q+q\log q)$

关键在于：能不能从 $F(n,m)$ 出发，花 $\mathcal O(1)$ 时间把 $n$ 或 $m$ 移动一格？

### 四种移动

先看 $m$。增加或删除末尾一项就有

$$
\begin{aligned}
F(n,m+1)&=F(n,m)+\binom n{m+1},\\
F(n,m-1)&=F(n,m)-\binom nm.
\end{aligned}
$$

再看 $n$。将杨辉三角的递推式累加：

$$
\begin{aligned}
F(n+1,m)
&=\sum_{k=0}^{m}\left(\binom nk+\binom n{k-1}\right)\\
&=F(n,m)+F(n,m-1)\\
&=2F(n,m)-\binom nm.
\end{aligned}
$$

反过来得到

$$
F(n-1,m)=\frac{F(n,m)+\binom{n-1}{m}}2.
$$

上述相邻状态递推是[自为风月马前卒总结的核心 Trick](https://www.cnblogs.com/zwfymqz/p/9751173.html#_label0)。维护当前状态 $(n,m,s)$，其中 $s=F(n,m)$，就能把询问看成二维平面上的点，用莫队安排访问顺序。

这里的 $n,m$ 并不是普通区间的左右端点，不要求移动过程满足 $m\le n$。只要组合数函数在越界时返回零，四个式子依然成立。例如 $m>n$ 时 $F(n,m)=2^n$，增加 $n$ 的公式仍然正确。

### 排序与复杂度

由于 $m\ge n$ 后答案不变，可以先令 $m\gets\min(m,n)$。按 $n$ 所在块排序，块内让 $m$ 单调移动，奇偶块使用相反方向。

代码取块长

$$
B\approx\max\left(1,\frac{n+1}{\sqrt{\max(1,q)}}\right).
$$

代入后，第一维的移动量为 $\mathcal O(n\sqrt q+q)$；第二维已经截断到不超过 $n$，移动量为 $\mathcal O(n\sqrt q)$。再计入 $\mathcal O(n)$ 的阶乘预处理和 $\mathcal O(q\log q)$ 的排序，非空询问时总时间为

$$
\boxed{\mathcal O(n\sqrt q+q\log q)}.
$$

空间为 $\mathcal O(n+q)$。这里的时间上界适用于代码实际使用的块长，没有把 $q$ 与 $n$ 合并。

组合数通过阶乘和逆阶乘 $\mathcal O(1)$ 计算，因此这份代码要求 $n<p$，而且 $n$ 不能大到无法预处理。不能把一个 $10^{18}$ 级别的 $n$ 直接放进这个实现。

### 代码

最容易写错的是减小 $n$ 的操作：公式中使用 $\binom{n-1}{m}$，所以代码先 `--n` 再计算组合数。减小 $m$ 时则相反，要先减去当前末项再 `--m`。

```cpp
#include<algorithm>
#include<cmath>
#include<iostream>
#include<vector>
using std::cin;
using std::cout;
using std::ios;
using std::max;
using std::min;
using std::sort;
using std::sqrt;
using std::vector;
using i64=long long;
const int P=998244353,INV2=(P+1)/2;
inline int inc(int a,int b){return(a+=b)>=P?a-P:a;}
inline int dec(int a,int b){return(a-=b)<0?a+P:a;}
inline int mul(int a,int b){return (1ll*a*b%P+P)%P;}
inline void add(int &a,int b){(a+=b)>=P?a-=P:1;}
inline void sub(int &a,int b){(a-=b)<0?a+=P:1;}
inline int qpow(int a,int b){int res=1;while(b){if(b&1)res=mul(res,a);a=mul(a,a);b>>=1;}return res;}
inline int Inv(int x){return qpow(x,P-2);}
struct Query{int n,m,id;};
int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    int q,N=0;
    cin>>q;
    vector<Query>ask(q);
    for(int i=0;i<q;i++){
        cin>>ask[i].n>>ask[i].m;
        ask[i].m=min(ask[i].m,ask[i].n);
        ask[i].id=i;
        N=max(N,ask[i].n);
    }
    vector<int>fac(N+1,1),ifac(N+1,1);
    for(int i=1;i<=N;i++)fac[i]=mul(fac[i-1],i);
    ifac[N]=Inv(fac[N]);
    for(int i=N;i>=1;i--)ifac[i-1]=mul(ifac[i],i);
    auto C=[&](int n,int k)->int{
        if(k<0||k>n)return 0;
        return mul(mul(fac[n],ifac[k]),ifac[n-k]);
    };
    int B=max(1,int((N+1)/sqrt(max(1,q))));
    sort(ask.begin(),ask.end(),[&](const Query&a,const Query&b){
        int x=a.n/B,y=b.n/B;
        if(x!=y)return x<y;
        return(x&1)?a.m>b.m:a.m<b.m;
    });
    vector<int>ans(q);
    int n=0,m=0,s=1;
    for(auto query:ask){
        while(n<query.n){
            s=dec(inc(s,s),C(n,m));
            ++n;
        }
        while(n>query.n){
            --n; // 这里需要的是 C(n - 1, m)，先移动再取组合数。
            s=mul(inc(s,C(n,m)),INV2);
        }
        while(m<query.m){
            ++m;
            add(s,C(n,m));
        }
        while(m>query.m){
            sub(s,C(n,m));
            --m;
        }
        ans[query.id]=s;
    }
    for(int x:ans)cout<<x<<'\n';
}
```

## 3. 网格预处理 + 整式递推：$\mathcal O((n^{6/5}+qn^{1/5})\log n)$

[Entropy Increaser 的文章](https://blog.csdn.net/EI_Captain/article/details/113142893)在莫队之后，先用较稀疏的网格保存状态，再快速补上网格点到询问点之间的短距离。本节将这个方案所需的整式递推与等距插值一并展开。

这一节要求所有询问满足 $0\le n_i\le n<p$，先将 $m$ 截断为 $\min(m,n)$。与后面的“大 $n$ 多项式求值”不同，这里需要预处理到 $n$。

### 把横向、纵向移动统一成矩阵

为方便后续代码，使用行向量

$$
\mathbf v_{n,m}=\begin{bmatrix}\binom nm&F(n,m)\end{bmatrix}.
$$

横向增加 $m$ 时，

$$
\mathbf v_{n,m+1}
=\mathbf v_{n,m}\frac1{m+1}
\begin{bmatrix}
n-m&n-m\\
0&m+1
\end{bmatrix}.
$$

纵向增加 $n$ 时，

$$
\mathbf v_{n+1,m}
=\mathbf v_{n,m}\frac1{n-m+1}
\begin{bmatrix}
n+1&-(n-m+1)\\
0&2(n-m+1)
\end{bmatrix}.
$$

这个状态的两项顺序与参考文章相反，因此矩阵也相应调整。每步先提出一个标量分母，剩下的是元素次数至多为 $1$ 的多项式矩阵。实际计算时只存上三角的三个元素 $(a,b,d)$，按

$$
(a_1,b_1,d_1)\circ(a_2,b_2,d_2)
=(a_1a_2,\ a_1b_2+b_1d_2,\ d_1d_2)
$$

合并，不能调换乘法顺序。

从 $(n,m)$ 开始连续移动 $L$ 步，横向分母的乘积是 $(m+L)!/m!$，纵向分母的乘积是 $(n-m+L)!/(n-m)!$。阶乘、逆阶乘预处理后，就能在 $\mathcal O(1)$ 时间统一除去它们。

### 等距点平移：用一次卷积完成一批插值

这一子程序单独用 $n$ 表示多项式次数、$m$ 表示目标点数。需要的操作是：已知次数不超过 $n$ 的多项式 $f$ 在 $0,1,\ldots,n$ 处的值，求

$$
f(c),f(c+1),\ldots,f(c+m-1).
$$

由拉格朗日插值，设

$$
w_j=\frac{(-1)^{n-j}f(j)}{j!(n-j)!},
$$

当 $c+i$ 没有命中原采样点时，

$$
f(c+i)=\left(\prod_{j=0}^{n}(c+i-j)\right)
\sum_{j=0}^{n}\frac{w_j}{c+i-j}.
$$

令 $b_k=(c-n+k)^{-1}$，则右侧求和恰好是卷积 $w*b$ 的第 $n+i$ 项。括号中的连乘可以用滑动窗口维护，所以整个平移操作只需

$$
\mathcal O((n+m)\log(n+m))
$$

时间，而不是一般多点求值的两个 $\log$。

当 $c+i$ 命中 $0,\ldots,n$ 时，直接返回已知值。代码对逆元数组中的零置零，并为滑动窗口单独记录零因子的数量，从而也能正确处理取模后绕回零点的情况；不会尝试对零求逆。

### 倍增得到矩阵乘积的采样值

以下两个子程序用 $n$ 表示目标递推长度。固定横向或纵向移动中的另一维，记提出分母后的单步矩阵为 $A(t)$，其元素关于偏移量 $t$ 都是一次多项式。定义有序乘积

$$
P_L(t)=A(t)A(t+1)\cdots A(t+L-1).
$$

每个元素的次数至多为 $L$，并且

$$
P_{2L}(t)=P_L(t)P_L(t+L).
$$

选定非零步长 $h$，假设已经知道 $P_L(jh)$，$j=0,\ldots,L$。把 $t$ 换成 $hu$ 后，两次等距插值分别给出

$$
P_L(jh),\qquad P_L(jh+L),\qquad j=0,\ldots,2L.
$$

第二批对应采样坐标平移 $L/h$。逐点按顺序相乘，就得到 $P_{2L}(jh)$。设目标长度 $n$ 是二次幂，从 $L=1$ 不断倍增到 $n$，总时间由各轮规模的几何级数控制：

$$
\sum_{j=1}^{\log_2 n}j2^j=\mathcal O(n\log n).
$$

注意这里始终维护**等距点值**，没有在每轮重建一般的余式树。这一点保证了后面的复杂度。

### 单次短距离转移为什么只需平方根时间

要计算从某个起点起的 $n$ 步矩阵乘积，取二次幂 $D\asymp\sqrt n$，并设采样步长 $h=D$。

倍增得到 $P_D(jD)$ 后，先依次相乘所有完整块，最后不足 $D$ 步的部分直接递推。完整块最多 $\mathcal O(\sqrt n)$ 个，因此总时间为

$$
\mathcal O(\sqrt n\log n).
$$

代码令 $D$ 为不小于 $\sqrt n$ 的最小二次幂，此时完整块数不超过 $D$，所需值已经包含在 $j=0,\ldots,D$ 的采样结果中。

### 预处理粗网格，再回答询问

这里恢复主问题的规模记号：$n=\max n_i$，$m=\max m_i$，$q$ 为询问数。代码取网格间距为二次幂 $B\asymp n^{2/5}$，满足 $B\le\sqrt n$，预处理所有合法的 $(iB,jB)$，其中 $0\le j\le i$。

对于固定的一行 $u=iB$，从 $(u,0)$ 的状态 $(1,1)$ 开始。先求出连续 $B$ 步横向转移的采样值，再一次平移求出所有块起点 $0,B,2B,\ldots$ 对应的矩阵。依次应用这些矩阵，就能填完这一行。

一行需要处理的网格点数为 $\mathcal O(n^{3/5})$，倍增所需的采样规模为 $\mathcal O(n^{2/5})$。因此一行的时间为 $\mathcal O(n^{3/5}\log n)$，共有 $\mathcal O(n^{3/5})$ 行，网格预处理总时间为

$$
\mathcal O(n^{6/5}\log n).
$$

对询问 $(n_i,m_i)$，找到左下角网格点

$$
n_0=B\lfloor n_i/B\rfloor,\qquad m_0=B\lfloor m_i/B\rfloor.
$$

从 $(n_0,m_0)$ **先增加第一维，再增加第二维**，两段长度都小于 $B$。因为已将 $m_i$ 截断为不超过 $n_i$，有 $m_0\le n_0$，沿这条路径始终处于第二维不超过第一维的区域，纵向分母不会为零。

代入 $B\asymp n^{2/5}$，每次询问需要 $\mathcal O(n^{1/5}\log n)$ 时间。因此，包括阶乘预处理和读取询问，非空输入的总时间为

$$
\boxed{\mathcal O((n^{6/5}+qn^{1/5})\log n)}.
$$

块长的选择来自原题的同阶条件：网格规模与 $n^2/B^2$ 成正比，全部短距离转移的主项与 $q\sqrt B$ 成正比；当 $q$ 与 $n$ 同阶时，平衡两者就得到 $B\asymp n^{2/5}$。上面的总时间仍显式保留 $q$，与当前代码固定使用这一块长的行为一致。

空间为 $\mathcal O(n^{6/5}+q)$。这份实现预处理整个三角网格，因此这个上界不依赖 $m$。如果每次从网格点暴力走完剩余步数，单次会退化为 $\mathcal O(n^{2/5})$；`shortProduct` 实现了真正的平方根转移。全部 $n_i=0$ 时，程序直接得到各答案为 $1$，只需 $\mathcal O(q)$ 时间。

### 代码

将文末公共多项式代码放在下面代码之前。这里的 `shiftValues`、`productSamples`、`shortProduct` 分别对应等距插值、矩阵乘积倍增和单次整式递推。

```cpp
// 放在公共多项式代码之后。
int norm(i64 x){
    x%=P;
    return x<0?x+P:x;
}
struct Factorials{
    vector<int>fac,ifac;
    explicit Factorials(int n):fac(n+1,1),ifac(n+1,1){
        for(int i=1;i<=n;i++)fac[i]=mul(fac[i-1],i);
        ifac[n]=Inv(fac[n]);
        for(int i=n;i;i--)ifac[i-1]=mul(ifac[i],i);
    }
    int invRising(int start,int len)const{
        return mul(fac[start],ifac[start+len]);
    }
};

// 批量求非零元素的逆元；零元素的返回值约定为零。
vector<int>batchInverse(const vector<int>&a){
    int n=a.size();
    vector<int>pre(n+1,1),result(n);
    for(int i=0;i<n;i++)
        pre[i+1]=a[i]?mul(pre[i],a[i]):pre[i];
    int inv=Inv(pre[n]);
    for(int i=n-1;i>=0;i--)if(a[i]){
        result[i]=mul(inv,pre[i]);
        inv=mul(inv,a[i]);
    }
    return result;
}

// 已知 deg(f)<=d 和 f(0)..f(d)，求 f(start)..f(start+count-1)。
vector<int>shiftValues(const vector<int>&y,int start,int count,const Factorials&ft){
    if(!count)return{};
    int d=(int)y.size()-1;
    if(start==0&&count<=d+1)
        return vector<int>(y.begin(),y.begin()+count);
    vector<int>a(d+1),factors(d+count);
    for(int j=0;j<=d;j++){
        a[j]=mul(mul(y[j],ft.ifac[j]),ft.ifac[d-j]);
        if((d-j)&1)a[j]=dec(0,a[j]);
    }
    for(int j=0;j<d+count;j++)factors[j]=norm(i64(start)-d+j);
    vector<int>inv=batchInverse(factors);
    poly conv=poly(a)*poly(inv);
    vector<int>answer(count);
    conv.resize(2*d+count);
    int product=1,zeros=0;
    for(int j=0;j<=d;j++){
        if(factors[j])product=mul(product,factors[j]);
        else++zeros;
    }
    for(int i=0;i<count;i++){
        int x=norm(i64(start)+i);
        if(x<=d)answer[i]=y[x]; // 命中已有采样点，直接取值。
        else answer[i]=zeros?0:mul(product,conv[d+i]);
        if(i+1==count)break;
        if(factors[i])product=mul(product,inv[i]);
        else--zeros;
        if(factors[i+d+1])product=mul(product,factors[i+d+1]);
        else++zeros;
    }
    return answer;
}

// 上三角矩阵 [[a,b],[0,d]]，状态为行向量 (C,F)。
struct Tri{int a=1,b=0,d=1;};
Tri multiply(Tri x,Tri y){
    return{mul(x.a,y.a),inc(mul(x.a,y.b),mul(x.b,y.d)),mul(x.d,y.d)};
}
struct State{int c=1,s=1;};
void apply(State&v,Tri t,int invDen){
    v.s=mul(inc(mul(v.c,t.b),mul(v.s,t.d)),invDen);
    v.c=mul(mul(v.c,t.a),invDen);
}

// 固定 n 横向移动，或固定 m 纵向移动；t 为从起点起的偏移量。
struct AffineStep{
    bool vertical;
    int n,m;
    Tri operator()(int t)const{
        if(!vertical){
            int a=norm(i64(n)-m-t);
            return{a,a,norm(i64(m)+t+1)};
        }
        int z=norm(i64(n)+t-m+1);
        return{norm(i64(n)+t+1),dec(0,z),inc(z,z)};
    }
};

vector<Tri>shiftMatrices(const vector<Tri>&y,int start,int count,const Factorials&ft){
    vector<int>a,b,d;
    for(Tri x:y){a.push_back(x.a);b.push_back(x.b);d.push_back(x.d);}
    a=shiftValues(a,start,count,ft);
    b=shiftValues(b,start,count,ft);
    d=shiftValues(d,start,count,ft);
    vector<Tri>result(count);
    for(int i=0;i<count;i++)result[i]={a[i],b[i],d[i]};
    return result;
}

// len 是 2 的幂。返回 P_len(j*stride)，j=0..len。
vector<Tri>productSamples(AffineStep step,int len,int stride,const Factorials&ft){
    assert(len>0&&(len&(len-1))==0);
    vector<Tri>y{step(0),step(stride)};
    int invStride=Inv(stride);
    for(int k=1;k<len;k<<=1){
        auto left=shiftMatrices(y,0,2*k+1,ft);
        auto right=shiftMatrices(y,mul(k,invStride),2*k+1,ft);
        y.resize(2*k+1);
        for(int j=0;j<=2*k;j++)y[j]=multiply(left[j],right[j]);
    }
    return y;
}

// 用平方根分块加速一段整式递推；所有分母稍后统一处理。
Tri shortProduct(AffineStep step,int len,const Factorials&ft){
    if(!len)return{};
    int block=1;
    while(i64(block)*block<len)block<<=1;
    auto samples=productSamples(step,block,block,ft);
    Tri result;
    int complete=len/block;
    for(int j=0;j<complete;j++)result=multiply(result,samples[j]);
    for(int t=complete*block;t<len;t++)result=multiply(result,step(t));
    return result;
}

int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    init_w();
    int q,N=0;
    cin>>q;
    vector<pair<int,int>>ask(q);
    for(auto&[n,m]:ask){
        cin>>n>>m;
        assert(0<=n&&n<P&&m>=0);
        m=min(m,n);N=max(N,n);
    }
    Factorials ft(N);
    int B=1; // 取不超过 N^(2/5) 的最大二次幂。
    while(true){
        long double next=2*B;
        if(next*next*next*next*next>1.L*N*N)break;
        B*=2;
    }
    int rows=N/B;
    vector<vector<State>>grid(rows+1);
    for(int i=0;i<=rows;i++){
        int n=i*B;
        grid[i].resize(i+1);
        if(!i)continue;
        auto samples=productSamples({false,n,0},B,B,ft);
        auto jumps=shiftMatrices(samples,0,i,ft);
        State cur;
        for(int j=0;j<i;j++){
            apply(cur,jumps[j],ft.invRising(j*B,B));
            grid[i][j+1]=cur;
        }
    }
    for(auto[n,m]:ask){
        int n0=n/B*B,m0=m/B*B;
        State cur=grid[n/B][m/B];
        int dn=n-n0,dm=m-m0;
        apply(cur,shortProduct({true,n0,m0},dn,ft),ft.invRising(n0-m0,dn));
        apply(cur,shortProduct({false,n,m0},dm,ft),ft.invRising(m0,dm));
        cout<<cur.s<<'\n';
    }
}
```

## 4. 二进制分层 + 批量求值：$\mathcal O((n+q)\log^3(n+q))$

[同一篇文章](https://blog.csdn.net/EI_Captain/article/details/113142893)还给出了逐层细化网格的方案。它依然使用上节的两种矩阵转移，但不必先撒出一个固定粗网格，而是只处理输入询问实际需要的移动。

### 每层为两个坐标各补一个二进制位

继续要求 $n<p$，并先截断 $m\gets\min(m,n)$。让 $B$ 从不超过 $n$ 的最高二次幂开始，每次减半。

处理大小为 $B$ 的这一层之前，第 $i$ 个询问已经位于

$$
\left(
2B\left\lfloor\frac{n_i}{2B}\right\rfloor,
2B\left\lfloor\frac{m_i}{2B}\right\rfloor
\right).
$$

先检查 $n_i$ 的这一位：若为 $1$，将当前 $n$ 增加 $B$；再检查 $m_i$ 的这一位：若为 $1$，将当前 $m$ 增加 $B$。这一层结束后，就到达间距为 $B$ 的网格，直到 $B=1$ 时抵达询问本身。

顺序仍然是先纵向、再横向。纵向结束后的 $n$ 已经是 $B\lfloor n_i/B\rfloor$，而目标 $m$ 不超过 $B\lfloor m_i/B\rfloor\le B\lfloor n_i/B\rfloor$，所以不会越过对角线。

### 把同一行、同一列的移动放在一起

纵向阶段，把所有起始 $n=u$ 且需要增加 $B$ 的询问分为一组；把 $m$ 当作变量 $x$，构造

$$
P^{\downarrow}_{u,B}(x)
=\prod_{t=u}^{u+B-1}
\begin{bmatrix}
t+1&x-t-1\\
0&2(t+1-x)
\end{bmatrix}.
$$

这是一个元素次数至多为 $B$ 的多项式矩阵。对这一组询问的当前 $m$ 批量求值，再除去对应分母，即可同时完成它们的纵向移动。

横向阶段按起始 $m=v$ 分组，把 $n$ 当作变量 $x$，构造

$$
P^{\rightarrow}_{v,B}(x)
=\prod_{t=v}^{v+B-1}
\begin{bmatrix}
x-t&x-t\\
0&t+1
\end{bmatrix}.
$$

然后在当前 $n$ 处多点求值，完成横向移动。两种乘积都按 $t$ 递增的顺序合并。

例如同一层中的 $(u,m_1)$、$(u,m_2)$ 都需要走到第 $u+B$ 行，它们共享同一个 $P^{\downarrow}_{u,B}(x)$，只是在 $x=m_1,m_2$ 处取不同的点值。这就是批量处理的来源。

### 复杂度

在一层中，纵向组和横向组的起点都是 $2B$ 的倍数。每个方向的非空组数不超过 $n/B$，每组多项式次数至多为 $B$，因此所有组的次数之和为 $\mathcal O(n)$。询问点数之和则不超过 $q$。

下面的代码用普通的平衡乘积树构造矩阵多项式，同一层所有组的构造时间合计为 $\mathcal O(n\log^2 n)$。原文进一步利用结构，能将同层的这一部分做到 $\mathcal O(n\log n)$；这里使用通用乘积树，仍然不影响整套算法的 $\mathcal O((n+q)\log^3(n+q))$ 总界。

配合一般多点求值，每层总时间上界为

$$
\mathcal O((n+q)\log^2(n+q)).
$$

共有 $\mathcal O(\log n)$ 层，所以总时间为

$$
\boxed{\mathcal O((n+q)\log^3(n+q))}.
$$

代码每次只处理一个组，空间上界为 $\mathcal O((n+q)\log(n+q))$。重复的点值可以直接交给余式树处理。

这一做法与下一节的前缀分解法在各参数同阶时有相同的渐进复杂度，但实际依赖的规模不同：本节按二维网格逐层移动，需要 $n$ 较小；下一节只沿 $m$ 这一维组织递推，可以处理很大的 $n$。

### 代码

```cpp
        }
```

## 5. 前缀分解 + 多点求值：$\mathcal O((m+q)\log^3(m+q))$

下面不再要求 $n$ 小。把 $n$ 当成变量 $x$，定义

$$
c_k(x)=\frac{x(x-1)\cdots(x-k+1)}{k!},\qquad
f_k(x)=\sum_{i=0}^{k}c_i(x).
$$

它们都是至多 $k$ 次多项式。因为 $k\le m<p$，分母可逆，所以对于任意非负整数 $n$，包括 $n\ge p$，都有

$$
F(n,m)=f_m(n\bmod p).
$$

注意：这里只是**小于 $p$ 的下标对应的组合数多项式**可以这样处理。如果允许 $m\ge p$，$m!$ 可能为零，不能继续套这套除法。

### 把递推写成区间变换

记

$$
a_k(x)=\frac{x-k+1}{k}.
$$

每一步的状态变化为

$$
(c,s)\longmapsto(ca_k,\ s+ca_k).
$$

于是某一整段递推也可以用两个多项式 $(A,B)$ 描述：

$$
(c,s)\longmapsto(cA,\ s+cB).
$$

单步为 $(A,B)=(a_k,a_k)$，空区间为 $(1,0)$。先经过左区间、再经过右区间时，有

$$
\boxed{
A=A_LA_R,\qquad B=B_L+A_LB_R.
}
$$

例如第 $1,2$ 步合并后，$A=a_1a_2$、$B=a_1+a_1a_2$。初始状态是 $(c_0,f_0)=(1,1)$，所以得到 $f_2=1+a_1+a_1a_2$，恰好是前三项之和。

等价的矩阵写法为

$$
\begin{bmatrix}c_k&f_k\end{bmatrix}
=\begin{bmatrix}c_{k-1}&f_{k-1}\end{bmatrix}
\begin{bmatrix}a_k&a_k\\0&1\end{bmatrix}.
$$

这对应[洛谷参考中的矩阵前缀积建模](https://www.luogu.com/article/261ttwej)。实现时只存 $(A,B)$，利用右下角恒为 $1$、左下角恒为 $0$ 的结构，合并只需两次卷积。

### 按询问建树

将询问按 $m$ 从小到大排序，记为 $(x_1,m_1),\ldots,(x_q,m_q)$，并令 $m_0=0$。

第 $i$ 个叶子存储从 $m_{i-1}+1$ 到 $m_i$ 的整段变换。相同 $m$ 对应空区间，直接存单位变换；所以不需要假定“每个前缀恰好只有一个询问”。

在这些叶子上建立平衡线段树，每个内部结点合并左右儿子的变换。第 $i$ 个询问需要前 $i$ 个叶子的乘积，把前缀 $[1,i]$ 拆成 $\mathcal O(\log q)$ 个结点即可。

对于某个结点 $v$，收集所有会用到它的询问，将 $A_v,B_v$ 在这些询问的 $x_i$ 处一起做多点求值。然后对每个询问的数值状态应用

$$
c_i\gets c_iA_v(x_i),\qquad
s_i\gets s_i+c_i^{\mathrm{old}}B_v(x_i).
$$

一个询问的区间变换必须按从左到右的顺序应用。代码使用先处理当前结点、再遍历左儿子和右儿子的方式；同一个询问选出的结点互不包含，因此它们会按所需顺序被访问。

### 为什么有三个 $\log$

对于次数不超过 $m$ 的多项式，在至多 $q$ 个点求值，乘积树和余式树可以在

$$
\mathcal O((m+q)\log^2(m+q))
$$

时间内完成。先构造 $H(x)=\prod_j(x-x_j)$，将多项式对 $H$ 取模，再沿乘积树逐层取模，叶子上的常数就是点值。

在外层线段树的同一深度，各结点的递推区间互不相交，次数总和不超过 $m$；每个询问在这一层最多选一个结点，求值点数总和不超过 $q$。一层的上界为 $\mathcal O((m+q)\log^2(m+q))$，再乘上外层树高，就得到 $\mathcal O((m+q)\log^3(m+q))$。

这里多出来的一层 $\log$，来自每个询问在多个区间上反复做多点求值。这个中间做法也对应[zhoukangyang 提到的线段树方案](https://www.cnblogs.com/zkyJuruo/p/16995141.html)。

空间为 $\mathcal O((m+q)\log(m+q))$，包括区间多项式、询问归属列表，以及当前多点求值的乘积树。

```cpp
struct Solver:TransitionTree{
    vector<vector<int>>take;
    vector<int>c,s;
    explicit Solver(vector<Query>ask):TransitionTree(std::move(ask)),
        take(4*q+4),c(q,1),s(q,1){}
    void attach(int u,int l,int r,int id){
        if(r<=id){take[u].push_back(id);return;}
        int mid=(l+r)/2;
        attach(u*2,l,mid,id);
        if(id>mid)attach(u*2+1,mid+1,r,id);
    }
    void work(int u,int l,int r){
        if(!take[u].empty()){
            vector<int>points;
            for(int id:take[u])points.push_back(ask[id].x);
            MultiEval evaluator(points);
            vector<int>a=evaluator.eval(tr[u].a);
            vector<int>b=evaluator.eval(tr[u].b);
            for(int j=0;j<(int)take[u].size();j++){
                int id=take[u][j];
                add(s[id],mul(c[id],b[j]));
                c[id]=mul(c[id],a[j]);
            }
        }
        if(l==r)return;
        int mid=(l+r)/2;
        work(u*2,l,mid);
        work(u*2+1,mid+1,r);
    }
    vector<int>solve(){
        if(!q)return{};
        for(int i=0;i<q;i++)attach(1,0,q-1,i);
        work(1,0,q-1);
        vector<int>ans(q);
        for(int i=0;i<q;i++)ans[ask[i].id]=s[i];
        return ans;
    }
};
```

## 6. 分治取模：$\mathcal O((m+q)\log^2(m+q))$

上一节是先把一个询问拆到多个结点，再分别求值。现在考虑让所有询问共享一棵求值乘积树，并在向下递归时维护**进入当前区间前的状态**。

### 一个结点只保留它需要的余式

仍然按 $m$ 排序，使用完全相同的叶子和区间变换。对询问区间 $[l,r]$，定义

$$
H_{l,r}(x)=\prod_{i=l}^{r}(x-x_i).
$$

如果只关心这些 $x_i$ 处的值，那么对于任意多项式 $P$，都可以用

$$
P(x)\bmod H_{l,r}(x)
$$

替代 $P(x)$。因为二者之差是 $H_{l,r}$ 的倍数，在每个 $x_i$ 处都为零。

即使出现重复 $x_i$，这个结论也成立；不需要求导，也不需要去重。我们只取余并最终求点值，没有做要求点互异的插值。

进入结点 $[l,r]$ 时，维护两个多项式 $C,S$，使得

$$
\begin{aligned}
C&\equiv c_{m_{l-1}}\pmod {H_{l,r}},\\
S&\equiv f_{m_{l-1}}\pmod {H_{l,r}}.
\end{aligned}
$$

也就是说，它们表示所有询问在经过当前结点之前的共同状态。根结点之前没有执行任何一步，所以从 $C=S=1$ 开始。

### 向左右儿子传递

设左右儿子的模多项式分别为 $H_L,H_R$，左儿子的完整区间变换为 $(A_L,B_L)$。

进入左儿子前，不需要执行额外步骤，只需缩小模多项式：

$$
(C_L,S_L)=(C\bmod H_L,\ S\bmod H_L).
$$

进入右儿子前，必须先完整经过左区间，因此

$$
\boxed{
\begin{aligned}
C_R&=CA_L\bmod H_R,\\
S_R&=(S+CB_L)\bmod H_R.
\end{aligned}
}
$$

由于 $H_L,H_R$ 都整除父亲的 $H$，父亲处已经丢掉的高次项不会影响任何子树中的点值；取模又与加法、乘法相容，因此每一步都可以提前缩短多项式。

实现时先把 $C,S,A_L,B_L$ 分别对 $H_R$ 取模，再相乘、再取模。这样中间乘积的次数也能控制在右子树询问数的常数倍内。

注意，右儿子使用的是父亲状态经过**整个左区间变换**的结果，不是左递归返回的某一个询问答案。

### 叶子怎样回答

叶子 $i$ 的模多项式为 $x-x_i$，所以传入的 $C,S$ 已经是常数，代表执行到 $m_{i-1}$ 时的数值状态。再执行叶子本身的那一段变换，答案为

$$
F(n_i,m_i)=S+C\,B_i(x_i).
$$

若 $m_i=m_{i-1}$，叶子是空变换，$B_i=0$，答案自然就是 $S$。若全部 $m_i=0$，所有答案都是 $1$。

### 复杂度为什么少一层 $\log$

把建树和向下传递分开看：

1. 叶子对应的若干递推区间长度总和为 $m$。用分治乘法构造这些区间变换，再逐层合并，同一层的次数总和为 $\mathcal O(m)$，总时间为 $\mathcal O((m+q)\log^2(m+q))$。
2. 求值乘积树 $H$ 只建一次，同一层次数总和为 $q$，建树需要 $\mathcal O(q\log^2 q)$。
3. 向下传递时，状态次数被当前询问数限制。同一层的询问数总和为 $q$，会用到的左区间变换次数总和不超过 $m$。每个结点只做常数次多项式乘法和取模，一层共 $\mathcal O((m+q)\log(m+q))$，再乘树高得到 $\mathcal O((m+q)\log^2(m+q))$。
4. 叶子直接用 Horner 法计算 $B_i(x_i)$，所有叶子的次数之和不超过 $m$，这一部分只需 $\mathcal O(m+q)$。

所以最终总时间为

$$
\boxed{\mathcal O((m+q)\log^2(m+q))},
$$

空间为 $\mathcal O((m+q)\log(m+q))$。这里复杂度只依赖 $m,q$，不依赖原始 $n$ 的大小。

这就是[zhoukangyang 的分治取模思路](https://www.cnblogs.com/zkyJuruo/p/16995141.html)的一种具体实现：将线性因子按询问组织起来，把计算过程中的多项式状态限制在相关余式环中。和上一节相比，不再为每个区间单独重建一套多点求值流程。

### 代码

同样把文末公共代码放在这一段之前。`points.h` 与变换树使用相同的询问划分，所以结点编号一一对应。

```cpp
struct Solver:TransitionTree{
    MultiEval points;
    vector<int>ans;
    static vector<int>getPoints(const vector<Query>&ask){
        vector<int>x;
        for(const auto&v:ask)x.push_back(v.x);
        return x;
    }
    explicit Solver(vector<Query>queries):TransitionTree(std::move(queries)),
        points(getPoints(ask)),ans(q){}
    // c、s 是进入当前区间之前的状态，且已经对 points.h[u] 取模。
    void dfs(int u,int l,int r,const poly&c,const poly&s){
        if(l==r){
            int b=value(tr[u].b,ask[l].x);
            ans[ask[l].id]=inc(value(s,ask[l].x),mul(value(c,ask[l].x),b));
            return;
        }
        int mid=(l+r)/2;
        const poly&hl=points.h[u*2];
        const poly&hr=points.h[u*2+1];
        dfs(u*2,l,mid,c%hl,s%hl);

        // 右子树的询问先完整经过左区间。
        poly cr=c%hr,sr=s%hr;
        poly a=tr[u*2].a%hr;
        poly b=tr[u*2].b%hr;
        poly nextS=(sr+cr*b)%hr;
        poly nextC=cr*a%hr;
        dfs(u*2+1,mid+1,r,nextC,nextS);
    }
    vector<int>solve(){
        if(q)dfs(1,0,q-1,poly(1,1),poly(1,1));
        return ans;
    }
};
int main(){

    init_w();
    Solver solver(readQueries());

}
```

### 与 djq 分治的关系

[洛谷参考](https://www.luogu.com/article/261ttwej)还从矩阵前缀积的转置问题出发，利用系数反转和几何级数处理求值。其基础等式是：对次数不超过 $d$ 的多项式 $P$，

$$
P(a)=[t^d]\frac{t^dP(1/t)}{1-at}.
$$

若 $P(x)=\sum_{j=0}^{d}p_jx^j$，右边等于 $\sum_jp_ja^j$，因此成立。它把点值表达成一个系数，用来推导避免显式多项式取模的转置实现。

本文选择上面的余式树实现来完成 $\mathcal O((m+q)\log^2(m+q))$，便于直接说明不变量并给出完整代码。转置路线是同一复杂度下的另一种实现思路；仅写出这个系数等式，还不等于完成整套算法。

## 公共多项式代码

多项式部分采用 `namespace Poly`、`poly` 结构体和 `dif/dit` 模板，下方保留本文需要的加减乘除、取模、形式幂级数求逆，并补上多点求值和区间变换树。以下代码供第 3—6 节使用。**公共代码 + 第 3、4、5、6 节中任意一份代码**即可组成对应的独立程序，不要同时拼接多个 `main`。第 3、4 节主要使用其中的卷积和多点求值，第 5、6 节还使用区间变换树。

多项式系数从低次到高次存储在 `poly::a` 中。`poly(n,x)` 表示长度为 `n`、各项均为 `x` 的数组，所以常数 $1$ 写作 `poly(1,1)`；按系数构造则写作 `poly(vector<int>{a0,a1,...})`。

使用前必须调用一次 `init_w()`，第 3—6 节的 `main` 已加入这一步。`f*g`、`f/g`、`f%g` 分别表示多项式乘法、取商、取余；`f.inv()` 返回模 $x^{f.size()}$ 的幂级数逆，要求常数项非零。需要指定求逆精度时，先将 `f` 调整到对应长度。

空数组表示零多项式，运算过程中也允许保留高位零。除法和取模先用 `trim()` 去掉高位零：若被除式次数更低，商为零、余数为被除式；非零常数作除式时，余数为零。叶子求值也单独处理空数组。小规模乘法和取模直接递推，避免大量短多项式反复调用 NTT。

模板中 `L=20`，所有 NTT 长度都必须不超过 `Poly::N=1<<L`，包括 `inv()` 倍增时的 `o<<1`。扩大数据范围时需要相应调整 `L`，在当前模数下最多取 $23$。

其中多项式取模使用反转求商：若 $A=QB+R$，$\deg A=a$、$\deg B=b$，则令 $k=a-b+1$，有

$$
\operatorname{rev}_{a-b}Q
\equiv
\operatorname{rev}_{a}A\cdot(\operatorname{rev}_{b}B)^{-1}
\pmod{x^k},
$$

这里 $\operatorname{rev}_{d}P=x^dP(1/x)$。求出商后，用 $R=A-QB$ 得到余数。幂级数逆通过 Newton 迭代 $G\gets G(2-BG)$ 倍增精度，若在这一子程序中用 $n,m$ 表示两个输入多项式的次数上界，则一次乘法或取模的时间都是 $\mathcal O((n+m)\log(n+m))$。

```cpp
namespace Poly{

    const int ng=3;
    const int ngi=(P+1)/3;

    const int L=20;
    const int N=1<<L;

    int w[N],pinv[N];

    inline void init_w(){
        w[0]=pinv[1]=1;
        for(int i=0;i<L;i++)
            w[1<<i]=qpow(ng,(P-1)>>(i+2));
        for(int i=2;i<N;i++){
            w[i]=mul(w[i&-i],w[i&(i-1)]);
            pinv[i]=P-mul(P/i,pinv[P%i]);

    inline void dif(int *f,int n){
        int t,k,*tw,*tf,*pf;
        for(k=n>>1;k;k>>=1){

                for(pf=tf;pf!=tf+k;pf++){
                    t=mul(pf[k],*tw);
                    pf[k]=dec(*pf,t);
                    add(*pf,t);
                }
            }
        }
    }

        int t,k,*tw,*tf,*pf;
        for(k=1;k<n;k<<=1){
            for(tw=w,tf=f;tf!=f+n;tw++,tf+=k<<1){

                    t=pf[k];

                }

        }

        for(int i=0;i<n;i++)

        reverse(f+1,f+n);

    struct poly{
        vector<int>a;

            resize(max(n,m));

            a+=b;

            for(int i=0;i<n;i++)a[i]=f0[i];

            for(int i=0;i<n;i++)a[i]=f0[i];

                for(int i=0;i<n;i++)

            assert(lim<=N);

            idft(),resize(n+m-1);

        inline friend poly operator*(poly a,poly b){

                assert((o<<1)<=N);
                cp=a;cp.resize(o);cp.resize(o<<1);
                res.resize(o<<1);
                res.dft(),cp.dft();

// 一棵乘积树可以给多个多项式复用。
struct MultiEval{
    int n;
    vector<poly>h;
    explicit MultiEval(const vector<int>&x):n(x.size()),h(4*n+4){
        if(n)build(1,0,n-1,x);
    }
    void build(int u,int l,int r,const vector<int>&x){
        if(l==r){h[u]=vector<int>{dec(0,x[l]),1};return;}
        int mid=(l+r)/2;
        build(u*2,l,mid,x);build(u*2+1,mid+1,r,x);
        h[u]=h[u*2]*h[u*2+1];
    }
    void dfs(int u,int l,int r,const poly&f,vector<int>&ans)const{
        if(l==r){ans[l]=f.size()?f[0]:0;return;}
        int mid=(l+r)/2;
        dfs(u*2,l,mid,f%h[u*2],ans);
        dfs(u*2+1,mid+1,r,f%h[u*2+1],ans);
    }
    vector<int>eval(const poly&f)const{
        vector<int>ans(n);
        if(n)dfs(1,0,n-1,f%h[1],ans);
        return ans;
    }
};

// (c, s) -> (c * a, s + c * b)
struct Block{poly a=poly(1,1),b;};
Block join(const Block&left,const Block&right){
    return{left.a*right.a,left.b+left.a*right.b};
}
Block rangeProduct(int l,int r,const vector<int>&inv){
    if(l>r)return{};
    if(l==r){
        poly a(vector<int>{mul(dec(1,l),inv[l]),inv[l]});
        return{a,a};
    }
    int mid=(l+r)/2;
    return join(rangeProduct(l,mid,inv),rangeProduct(mid+1,r,inv));
}
struct Query{int x,m,id;};
vector<Query>readQueries(){

    cin>>q;
    vector<Query>ask(q);
    for(int i=0;i<q;i++){
        i64 n;
        int m;
        cin>>n>>m;
        assert(n>=0&&0<=m&&m<P);
        ask[i]={int(n%P),m,i};
    }
    stable_sort(ask.begin(),ask.end(),[](const Query&a,const Query&b){
        return a.m<b.m;
    });
    return ask;
}
struct TransitionTree{
    int q;
    vector<Query>ask;
    vector<Block>tr;
    explicit TransitionTree(vector<Query>queries)
        :q(queries.size()),ask(std::move(queries)),tr(4*q+4){
        if(!q)return;
        int m=ask.back().m;
        vector<int>inv(m+1);
        if(m)inv[1]=1;
        for(int i=2;i<=m;i++)
            inv[i]=dec(0,mul(P/i,inv[P%i]));
        build(1,0,q-1,inv);
    }
    void build(int u,int l,int r,const vector<int>&inv){
        if(l==r){
            int previous=l?ask[l-1].m:0;
            tr[u]=rangeProduct(previous+1,ask[l].m,inv);
            return;
        }
        int mid=(l+r)/2;
        build(u*2,l,mid,inv);build(u*2+1,mid+1,r,inv);
        tr[u]=join(tr[u*2],tr[u*2+1]);
    }
};
```

## 自检与容易踩的坑

- 初始状态为 $(\binom n0,F(n,0))=(1,1)$。忘掉 $k=0$ 的贡献会让全部答案少 $1$。
- 莫队中的组合数越界必须返回零；移动过程中 $m>n$ 是合法状态。
- 网格法、二进制分层先截断 $m$，再按“先增大 $n$、后增大 $m$”的顺序移动，防止纵向转移遇到零分母。
- 网格法的等距插值要处理命中采样点的情况；单次短转移需要平方根整式递推，不能直接走完 $B$ 步后仍声称原复杂度。
- 使用多项式前先调用 `init_w()`；`poly(1,1)` 才是常数 $1$，`poly(1)` 是长度为 $1$ 的零数组。
- 多项式变换的合并有顺序，$B=B_L+A_LB_R$，不能交换左右儿子。
- 更新 $(c,s)$ 时，新的 $s$ 要使用旧的 $c$。代码先更新 `s`，再更新 `c`。
- 重复的 $m$ 产生单位变换，重复的求值点也允许出现；不要为方便分析而在实现中漏掉这些情况。
- “$n$ 可以很大”依赖 $m<p$。莫队的阶乘实现则还要求 $n<p$，两者的适用范围不同。
