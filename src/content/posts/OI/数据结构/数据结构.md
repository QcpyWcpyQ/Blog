数据结构是计算机中**存储、组织和管理数据的方式**，它指相互之间存在一种或多种特定关系的数据元素的集合。

## 1 线性数据结构  

这一章节我们介绍**栈**、**队列**和**链表**。

### 1.1 栈

**栈（stack）**是一种抽象数据结构，作为元素的集合，主要包含两种操作。

1. **入栈（Push）**：向集合中添加一个元素； 
2. **出栈（Pop）**：移除最近添加的元素。

此外，还有一种**查看（peek）**操作，可以在不修改栈的情况下，返回最后添加的元素，即位于栈顶的元素的值。“栈”这一名称源于对物理物体（如一叠盘子）垂直堆叠的类比。

栈中元素的添加与移除顺序遵循**“后进先出”（Last In, First Out）**原则，通常缩写为 **LIFO**。这种结构使得从栈顶取出一个元素变得很容易，但若要访问栈中更深处的元素，通常需要先移除其他多个元素。

栈被视为一种线性集合，其一端是进行入栈和出栈操作的唯一位置，称为**“栈顶”（top）**；另一端则是固定的，称为**“栈底”（bottom）**。

#### 1.1.1 栈的实现

栈可以通过多种方式实现。

1. 数组模拟

   ```cpp
   #include<cassert>
   
   namespace Stack{
     const int N=1e6+5;
     int top=0,s[N];
     
     inline bool empty(){return top==0;}
     inline bool full(){return top==N;}
     inline int size(){return top;}
     inline void clear(){top=0;}
     inline void push(int v){
       assert(!full());
       s[++top]=0;
     }
     inline void pop(){
       assert(!empty());
       top--;
     }
     inline int top(){
       assert(!empty());
       return s[top];
     }
   }
   ```

2. C++ STL

   C++ 中的 STL 提供了一个容器 `std::stack`，使用前需要引入 `<stack>` 头文件。

   > STL 中对 `stack` 的定义
   >
   > ```cpp
   > // clang-format off
   > template<
   >  class T,
   >  class Container = std::deque<T>
   > > class stack;
   > ```
   >
   > `T` 为 `stack` 中存储的数据类型。
   >
   > `Container` 为用于存储元素的底层容器类型。这个容器需要提供 `back()`、`push_back()` 和 `pop_back()`。
   >
   > STL 容器 `std::vector`、`std::deque` 和 `std::list` 满足这些要求。如果不指定，则默认使用 `std::deque` 作为底层容器。

   STL 中的 `stack` 容器提供了一众成员函数以供调用，其中较为常用的有。

   - 元素访问
     - `s.top()` 返回栈顶
   - 修改
     - `s.push()` 插入传入的参数到栈顶
     - `s.pop()` 弹出栈顶
   - 容量
     - `s.empty()` 返回是否为空
     - `s.size()` 返回元素数量

   此外，可以使用赋值运算符 `=` 复制或清空一个栈。

   ```cpp
   #include<stack>
   
   std::stack<int>s;
   
   s.push(1);
   int value=s.top();
   s.pop();
   
   bool is_empty=s.empty();
   std::size_t count=s.size();
   s=std::stack<int>{};
   ```

栈的实现也可以设定容量限制。如果栈已满且没有足够的空间容纳新元素，则该栈处于**“栈溢出”（stack overflow）**状态。

### 1.2 队列

**队列（queue）**是一种抽象数据结构，作为元素的集合，主要包含两种操作。

1. **入队（Enqueue）**：在队列尾部添加一个元素；
2. **出队（Dequeue）**：从队列头部移除一个元素。

此外，还有一种**查看（peek）**操作，可以在不修改队列的情况下，返回下一个即将出队的元素，即位于队首的元素的值。“队列”这一名称源于人们排队等待商品或服务时的场景。

队列中元素的添加与移除顺序遵循**“先进先出”（First In, First Out）**原则，通常缩写为 **FIFO**。这种结构使得从队首取出一个元素变得很容易，但若要访问队列中更深处的元素，通常需要先移除其他多个元素。

队列被视为一种线性集合，其一端是进行入队操作的唯一位置，称为**“队尾”（tail）**；另一端则是进行出队操作的唯一位置，称为**“队首”（head）**。

#### 1.2.1 队列的实现

队列可以通过多种方式实现。

1. 数组模拟

   ```cpp
   #include<cassert>
   
   namespace Queue{
     const int N=1e6+5;
     int q[N],l=1,r=0;
     
     inline bool empty(){return l>r;}
     inline bool full(){return r==N;}
     inline int size(){return r-l+1;}
     inline void clear(){l=1,r=0;}
     inline void push(int v){
       assert(!full());
       q[++r]=v;
     }
     inline int front(){return q[l];}
     inline int back(){return q[r];}
     inline void pop(){
       assert(!empty());
       l++;
     }
   }
   ```

   使用数组模拟队列会导致一个问题：随着时间的推移，整个队列会向数组的尾部移动，一旦到达数组的最末端，即使数组的前端还有空闲位置，再进行入队操作也会导致溢出（这种数组里实际有空闲位置而发生了上溢的现象被称为“假溢出”）。

   解决假溢出的办法是采用循环的方式来组织存放队列元素的数组，即将数组下标为 0 的位置看做是最后一个位置的后继。（数组下标为 `x` 的元素，它的后继为 `(x + 1) % SIZE`）。这样就形成了循环队列。

3. C++ STL

   C++ 中的 STL 提供了一个容器 `std::queue`，使用前需要引入 `<queue>` 头文件。

   > STL 中对 `queue` 的定义
   >
   > ```cpp
   > // clang-format off
   > template<
   >     class T,
   >     class Container = std::deque<T>
   > > class queue;
   > ```
   >
   > `T` 为 `queue` 中存储的数据类型。
   >
   > `Container` 为用于存储元素的底层容器类型。这个容器需要提供 `back()`、`front()`、`push_back()` 和 `pop_front()`。
   >
   > STL 容器 `std::deque` 和 `std::list` 满足这些要求。如果不指定，则默认使用 `std::deque` 作为底层容器。

   STL 中的 `queue` 容器提供了一众成员函数以供调用，其中较为常用的有。

   - 元素访问
     - `q.front()` 返回队首元素
     - `q.back()` 返回队尾元素
   - 修改
     - `q.push()` 在队尾插入元素
     - `q.pop()` 弹出队首元素
   - 容量
     - `q.empty()` 队列是否为空
     - `q.size()` 返回队列中元素的数量

   此外，可以使用赋值运算符 `=` 复制或清空一个队列。

   ```cpp
   #include<queue>

   std::queue<int>q;

   q.push(1);
   int first=q.front();
   int last=q.back();
   q.pop();

   bool is_empty=q.empty();
   std::size_t count=q.size();
   q=std::queue<int>{};
   ```

4. 双端队列

   **双端队列（double-ended queue）**允许在队首和队尾插入或删除元素。C++ STL 使用 `std::deque` 实现双端队列，需要引入 `<deque>` 头文件。

   常用成员函数如下。

   - 元素访问
     - `dq.front()` 返回队首元素
     - `dq.back()` 返回队尾元素
     - `dq[index]` 返回下标为 `index` 的元素
   - 修改
     - `dq.push_front()` 在队首插入元素
     - `dq.push_back()` 在队尾插入元素
     - `dq.pop_front()` 弹出队首元素
     - `dq.pop_back()` 弹出队尾元素
     - `dq.clear()` 清空双端队列
   - 容量
     - `dq.empty()` 返回是否为空
     - `dq.size()` 返回元素数量

   ```cpp
   #include<deque>
   
   std::deque<int>dq;
   
   dq.push_front(1);
   dq.push_back(2);
   int first=dq.front();
   int last=dq.back();
   dq.pop_front();
   dq.pop_back();
   
   bool is_empty=dq.empty();
   std::size_t count=dq.size();
   dq.clear();
   ```


### 1.3 链表

链表是一种线性数据元素集合，其元素的顺序并非由它们在内存中的物理位置决定，而是通过每个元素指向下一个元素来确定的。它是一种由节点集合构成的数据结构，这些节点共同组成了一个序列。

在最基本的形式中，每个节点包含数据以及指向序列中下一个节点的引用。这种结构使得在遍历过程中，能够高效地在序列的任意位置插入或删除元素。更复杂的变体增加了额外的链接，从而允许在任意位置更高效地插入或删除节点（单点修改）。

链表的一个缺点是，访问数据所需的时间与链表中的节点数量成线性关系。由于节点是串行链接的，访问任意节点都必须先访问其前驱节点，因此无法实现更快的访问方式，如随机访问。与链表相比，数组具有更好的缓存局部性。

#### 1.3.1 单向链表

单向链表的每个节点包含一个值和一个指向后继节点的指针。链表只能沿着从前向后的方向遍历。

```cpp
#include<cassert>

namespace SinglyList{
  struct Node{
    int value;
    Node* next;
  };

  Node* head=nullptr;
  Node* tail=nullptr;
  int count=0;

  inline bool empty(){return count==0;}
  inline int size(){return count;}
  inline int front(){
    assert(!empty());
    return head->value;
  }
  inline int back(){
    assert(!empty());
    return tail->value;
  }
  inline void push_front(int v){
    Node* node=new Node{v,head};
    head=node;
    if(tail==nullptr)tail=node;
    count++;
  }
  inline void push_back(int v){
    Node* node=new Node{v,nullptr};
    if(tail!=nullptr)tail->next=node;
    else head=node;
    tail=node;
    count++;
  }
  inline Node* insert_after(Node* p,int v){
    assert(p!=nullptr);
    Node* node=new Node{v,p->next};
    p->next=node;
    if(tail==p)tail=node;
    count++;
    return node;
  }
  inline void pop_front(){
    assert(!empty());
    Node* node=head;
    head=head->next;
    delete node;
    count--;
    if(head==nullptr)tail=nullptr;
  }
  inline void erase_after(Node* p){
    assert(p!=nullptr&&p->next!=nullptr);
    Node* node=p->next;
    p->next=node->next;
    if(tail==node)tail=p;
    delete node;
    count--;
  }
  inline Node* find(int v){
    for(Node* p=head;p!=nullptr;p=p->next)
      if(p->value==v)return p;
    return nullptr;
  }
  inline void clear(){
    while(!empty())pop_front();
  }
}
```

已知节点位置时，在其后插入或删除节点的时间复杂度为 $O(1)$。查找节点和访问第 $k$ 个节点的时间复杂度为 $O(n)$。

#### 1.3.2 双向链表

双向链表的每个节点同时保存前驱和后继指针，因此可以向前或向后遍历。已知目标节点时，可以直接将其删除，无须重新寻找它的前驱。

```cpp
#include<cassert>

namespace DoublyList{
  struct Node{
    int value;
    Node* prev;
    Node* next;
  };

  Node* head=nullptr;
  Node* tail=nullptr;
  int count=0;

  inline bool empty(){return count==0;}
  inline int size(){return count;}
  inline int front(){
    assert(!empty());
    return head->value;
  }
  inline int back(){
    assert(!empty());
    return tail->value;
  }
  inline void push_front(int v){
    Node* node=new Node{v,nullptr,head};
    if(head!=nullptr)head->prev=node;
    else tail=node;
    head=node;
    count++;
  }
  inline void push_back(int v){
    Node* node=new Node{v,tail,nullptr};
    if(tail!=nullptr)tail->next=node;
    else head=node;
    tail=node;
    count++;
  }
  inline Node* insert_after(Node* p,int v){
    assert(p!=nullptr);
    Node* node=new Node{v,p,p->next};
    if(p->next!=nullptr)p->next->prev=node;
    else tail=node;
    p->next=node;
    count++;
    return node;
  }
  inline void erase(Node* p){
    assert(p!=nullptr);
    if(p->prev!=nullptr)p->prev->next=p->next;
    else head=p->next;
    if(p->next!=nullptr)p->next->prev=p->prev;
    else tail=p->prev;
    delete p;
    count--;
  }
  inline void pop_front(){
    assert(!empty());
    erase(head);
  }
  inline void pop_back(){
    assert(!empty());
    erase(tail);
  }
  inline Node* find(int v){
    for(Node* p=head;p!=nullptr;p=p->next)
      if(p->value==v)return p;
    return nullptr;
  }
  inline void clear(){
    while(!empty())pop_front();
  }
}
```

双向链表用额外的空间保存前驱指针，换取了反向遍历和 $O(1)$ 删除已知节点的能力。

#### 1.3.3 单向循环链表

单向循环链表的最后一个节点指向第一个节点，不存在值为 `nullptr` 的后继指针。只保存尾指针 `tail` 时，可以通过 `tail->next` 在 $O(1)$ 时间内访问链表头。

```cpp
#include<cassert>

namespace CircularSinglyList{
  struct Node{
    int value;
    Node* next;
  };

  Node* tail=nullptr;
  int count=0;

  inline bool empty(){return count==0;}
  inline int size(){return count;}
  inline Node* head(){return tail==nullptr?nullptr:tail->next;}
  inline int front(){
    assert(!empty());
    return tail->next->value;
  }
  inline int back(){
    assert(!empty());
    return tail->value;
  }
  inline void push_front(int v){
    Node* node=new Node{v,nullptr};
    if(tail==nullptr){
      node->next=node;
      tail=node;
    }else{
      node->next=tail->next;
      tail->next=node;
    }
    count++;
  }
  inline void push_back(int v){
    push_front(v);
    tail=tail->next;
  }
  inline Node* insert_after(Node* p,int v){
    assert(p!=nullptr);
    Node* node=new Node{v,p->next};
    p->next=node;
    if(tail==p)tail=node;
    count++;
    return node;
  }
  inline void erase_after(Node* p){
    assert(p!=nullptr&&p->next!=nullptr);
    Node* node=p->next;
    if(node==p){
      tail=nullptr;
    }else{
      p->next=node->next;
      if(tail==node)tail=p;
    }
    delete node;
    count--;
  }
  inline void pop_front(){
    assert(!empty());
    erase_after(tail);
  }
  inline Node* find(int v){
    if(empty())return nullptr;
    Node* p=tail->next;
    do{
      if(p->value==v)return p;
      p=p->next;
    }while(p!=tail->next);
    return nullptr;
  }
  inline void clear(){
    while(!empty())pop_front();
  }
}
```

遍历循环链表时不能以 `nullptr` 作为结束条件，应当在指针再次回到起点时停止。

#### 1.3.4 双向循环链表

双向循环链表中，头节点的前驱是尾节点，尾节点的后继是头节点。任意节点都可以沿两个方向遍历整个链表。

```cpp
#include<cassert>

namespace CircularDoublyList{
  struct Node{
    int value;
    Node* prev;
    Node* next;
  };

  Node* head=nullptr;
  int count=0;

  inline bool empty(){return count==0;}
  inline int size(){return count;}
  inline Node* tail(){return head==nullptr?nullptr:head->prev;}
  inline int front(){
    assert(!empty());
    return head->value;
  }
  inline int back(){
    assert(!empty());
    return head->prev->value;
  }
  inline void push_front(int v){
    Node* node=new Node{v,nullptr,nullptr};
    if(head==nullptr){
      node->prev=node->next=node;
    }else{
      Node* last=head->prev;
      node->prev=last;
      node->next=head;
      last->next=node;
      head->prev=node;
    }
    head=node;
    count++;
  }
  inline void push_back(int v){
    push_front(v);
    head=head->next;
  }
  inline Node* insert_after(Node* p,int v){
    assert(p!=nullptr);
    Node* node=new Node{v,p,p->next};
    p->next->prev=node;
    p->next=node;
    count++;
    return node;
  }
  inline void erase(Node* p){
    assert(p!=nullptr);
    if(count==1){
      head=nullptr;
    }else{
      p->prev->next=p->next;
      p->next->prev=p->prev;
      if(head==p)head=p->next;
    }
    delete p;
    count--;
  }
  inline void pop_front(){
    assert(!empty());
    erase(head);
  }
  inline void pop_back(){
    assert(!empty());
    erase(head->prev);
  }
  inline Node* find(int v){
    if(empty())return nullptr;
    Node* p=head;
    do{
      if(p->value==v)return p;
      p=p->next;
    }while(p!=head);
    return nullptr;
  }
  inline void clear(){
    while(!empty())pop_front();
  }
}
```

双向循环链表常与哨兵节点配合使用，以减少对空链表和边界节点的特殊判断。

#### 1.3.5 异或链表

异或链表使用一个整数保存前驱和后继地址的按位异或值，以一个字段代替双向链表中的两个指针。已知当前节点与前一个节点时，可以计算出下一个节点。

```cpp
#include<cassert>
#include<cstdint>

namespace XorList{
  struct Node{
    int value;
    std::uintptr_t link;
  };

  Node* head=nullptr;
  Node* tail=nullptr;
  int count=0;

  inline std::uintptr_t address(Node* p){
    return reinterpret_cast<std::uintptr_t>(p);
  }
  inline Node* other(std::uintptr_t link,Node* p){
    return reinterpret_cast<Node*>(link^address(p));
  }
  inline bool empty(){return count==0;}
  inline int size(){return count;}
  inline int front(){
    assert(!empty());
    return head->value;
  }
  inline int back(){
    assert(!empty());
    return tail->value;
  }
  inline void push_front(int v){
    Node* node=new Node{v,address(head)};
    if(head!=nullptr){
      Node* next=other(head->link,nullptr);
      head->link=address(node)^address(next);
    }else{
      tail=node;
    }
    head=node;
    count++;
  }
  inline void push_back(int v){
    Node* node=new Node{v,address(tail)};
    if(tail!=nullptr){
      Node* prev=other(tail->link,nullptr);
      tail->link=address(prev)^address(node);
    }else{
      head=node;
    }
    tail=node;
    count++;
  }
  inline void pop_front(){
    assert(!empty());
    Node* node=head;
    Node* next=other(node->link,nullptr);
    if(next!=nullptr){
      Node* next_next=other(next->link,node);
      next->link=address(next_next);
    }else{
      tail=nullptr;
    }
    head=next;
    delete node;
    count--;
  }
  inline void pop_back(){
    assert(!empty());
    Node* node=tail;
    Node* prev=other(node->link,nullptr);
    if(prev!=nullptr){
      Node* prev_prev=other(prev->link,node);
      prev->link=address(prev_prev);
    }else{
      head=nullptr;
    }
    tail=prev;
    delete node;
    count--;
  }
  inline Node* find(int v){
    Node* prev=nullptr;
    Node* current=head;
    while(current!=nullptr){
      if(current->value==v)return current;
      Node* next=other(current->link,prev);
      prev=current;
      current=next;
    }
    return nullptr;
  }
  inline void clear(){
    while(!empty())pop_front();
  }
}
```

异或链表节省了一个指针字段，但无法只根据当前节点直接得到相邻节点，调试和维护也更困难。它依赖 `std::uintptr_t` 及具体平台的指针表示，通常只适合用于理解链表和地址运算，不建议在实际工程中使用。
