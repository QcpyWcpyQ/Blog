- **Part 1 (Visual Studio Code)**
    1. Open VS Code and open the Desktop as the main folder.
    2. Create a folder called intro_to_cs.
    3. Restart VS Code and open intro_to_cs as the main folder.
    4. Create a file called file1.txt.
    5. Delete file1.txt.
    6. Create a folder called lab1.
    7. Inside the lab1 folder, create a file called lab1.txt.
    8. Add text to lab1.txt and save the file (Control+s in Windows/Linux,Command+s in MacOS).
    9. Copy the folder lab1 and paste it in the same place, There is anydifference between the two folders?
    10. Delete lab1 and their copy.
- **Part 2 (Console Commands)**
    1. Using `mkdir`, create a folder called *lab1_console*.
    2. Using `touch`, create a file called *file1.txt*.
    3. Using `cd`, navigate inside *lab1_console*.
    4. Using `touch`, create a file called *exercise1.txt*.
    5. Using `cd`, go back to *intro_to_cs* folder.
    6. Using `cp`, copy* file1.txt* into *lab1_console*.
    7. Using `mv`, move *exercise1.txt* from *lab1* to *intro_to_cs*.
    8. Using `rm`, delete *file1.txt*.
    9. Try to delete *lab1* using `rm`, what happened?
    10. Try to delete *lab1* using `rm`; but using the `-r` flag on the command, what happened?
